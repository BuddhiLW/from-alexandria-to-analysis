# Design specs

These are the design specs the widgets, playgrounds and era notebooks of the series were built from.
Docstrings in `alexandria/src` and `alexandria/media/src` refer to them by section, for example
"widget brief, section 5".

| file | covers |
|---|---|
| `common-brief.md` | the shape of an era: shelf data, proof steps, core namespaces, media, tests, notebook |
| `widget-brief.md` | widgets in the Road to Reality style: the raster backend, stepped definitions (section 4), tied controls (section 5), what each era gains (section 7) |
| `raster-brief.md` | the rule that symbolic work is Emmy and every number and animation runs on raster |
| `illustrate-brief.md` | illustrating the original works, era by era |
| `wave-c-verbatim.md` | the plan for following the originals verbatim, per era |

Docstrings that cite the "playground brief" refer to the free-form playground variant of the widget
spec (sections 4, 5 and 7 of `widget-brief.md`); there is no separate playground file.
